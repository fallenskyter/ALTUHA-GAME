# DUSK CRUSHER — PSP (C, PSPSDK)

Порт `DUSK_CRUSHER_Gothic_Arcade_v10.html` на C. Софтверный рендер 480×272, без GU.

## Сборка
Нужен установленный PSPSDK (pspdev). Из папки проекта:

    make            # даст EBOOT.PBP
    make package    # соберёт DUSKCRUSHER_PSP.zip с PSP/GAME/DUSKCRUSHER/

Скопируй папку `PSP/GAME/DUSKCRUSHER/` (EBOOT.PBP + папка `assets/`) на карту памяти. Без `assets/` игра запустится, но покажет «ASSETS MISSING».

## Управление
| Кнопка | Действие |
|---|---|
| Аналог / D-pad | двигать ногу (влево-вправо, вверх-вниз = высота) |
| ✕ | прижать / держать и вести стик = размазывать |
| ○ или □ | резкий удар / полное давление |
| L / R | наклон ступни |
| START | звуки вкл/выкл |
| △ | музыка вкл/выкл |

## Что сделано в этом этапе
- Анимированный город: небо, три слоя зданий, мигающие окна, неон, провода, летящие пылинки.
- Система слизи: брызги летят по дуге и оставляют пятна, размазывание оставляет полосы, лужи, тягучие нити при подъёме ноги, волна от удара, слизь на подошве.
- Портрет в 14 кадров + румянец, покачивание, рамка.
- HUD: 5 сердец, 4 точки множителя, счётчик «000», очки, комбо, лента бонусов.
- Звук: настоящие удар и хруст (хруст нарезается кусками с разной высотой тона) + синтезированные хруст кости, скрип кожи, хлюпанье (3 варианта), гул размазывания, низкий удар, писк муравьёв.

## Режим «кайфа» и музыка
Шкала счастья = 5 сердец (`hud.hype`, 0…5). Когда осталось 15% до заполнения (≥ 85%, то есть 4.25 из 5):
- запускается `assets/music.pcm` (твой трек, плавное появление за 0.8 с);
- портрет переходит в «кайф»: кадры 9, 11, 13, 7, усиленный румянец, розовое свечение, мигающая рамка, быстрое покачивание, из портрета поднимаются сердечки.
Если шкала падает ниже 60% (3.0 из 5), музыка плавно затихает. Следующее достижение 85% запускает трек заново с начала.
Пороги меняются в начале `src/main.c`: `MUSIC_START_AT`, `MUSIC_STOP_AT`.

## Файлы
- `src/main.c` — вся игра.
- `assets/boot_00..10.rgba` — позы ботинка 256×256 RGBA (из твоего прошлого архива).
- `assets/portraits.rgba` — 14 кадров 96×100 RGBA (вырезаны из листа в HTML).
- `assets/thud.pcm`, `assets/crunch.pcm` — звуки из HTML (s16, моно, 22050 Гц).
- `assets/music.pcm` — твой mp3, сконвертирован в s16, моно, 22050 Гц.

## Что не перенесено
Мусор (банки/пакеты/коробки) и "Trash Taken Out" пока нет. Вид ног сзади упрощён: вторая нога только поднимается на носок.
