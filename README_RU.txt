DUSK CRUSHER для PSP (C, PSPSDK) - этап 1

Что перенесено из HTML 1-в-1:
 - настоящие 11 поз ботинка, вырезанные из листа спрайтов (tools/gen_assets.py), с разметкой подошвы
 - ДВЕ ноги: передняя (игрок) и задняя (встаёт на носок при растирании/полном давлении)
 - точная физика ноги, машина поз, липкая слизь на подошве, отдача при приземлении
 - муравьи: WALK / PANIC / PINNED, крики, паника от ног, мусор (3 вида), всплывающие "+N"
 - режимы PIN / SOFT / SLOW_SMEAR / FULL_PRESSURE и подсчёт очков, комбо, множитель, сердечки, бонус-лента
 - зум мира 1.12, тряска экрана

Управление:
 START - начать / пауза, SELECT - звук
 Стик / D-pad - прицел (как мышь)
 CROSS (держать) - опускать и растирать; быстрый тап в воздухе - удар
 CIRCLE или R - полное давление / удар
 L / TRIANGLE - наклон носка вниз / вверх, SQUARE - выровнять

портрет с 14 кадрами, иконки HUD, все варианты звуков.
