DUSK CRUSHER для PSP (C, PSPSDK) - этап 2

Перенесено из HTML:
 - 11 поз ботинка из настоящего листа спрайтов, ДВЕ ноги, точная физика/позы/слизь на подошве
 - муравьи (WALK/PANIC/PINNED), мусор, всплывающие "+N", режимы PIN/SOFT/SMEAR/FULL, очки, комбо
 - город из HTML (предрендерен), анимированное неоновое свечение и пылинки
 - полная система слизи: лужи, мазки, брызги, тянущиеся нити слизи, ударные волны
 - портрет в правом верхнем углу: 14 кадров, румянец и радость растут от сердечек и точек
 - HUD как в оригинале: таймер, куча, шаги, бонус-лента, сердечки, 4 точки множителя, счётчик
 - звуки по рецептам оригинала (27 звуков): топот, хруст, ломание костей, скрежет, растирание
 - МУЗЫКА: когда шкала счастья (5 сердечек) заполнена на 85% и больше (осталось 15%),
   играет assets/music.pcm; затихает, когда шкала падает ниже 60%

Управление:
 START пауза, SELECT звук
 Стик / D-pad - прицел (как мышь)
 CROSS (держать) - опускать и растирать; быстрый тап в воздухе - удар
 CIRCLE или R - полное давление / удар
 L / TRIANGLE - наклон носка вниз / вверх, SQUARE - выровнять

ВАЖНО при загрузке на GitHub через браузер: папка .github не загружается автоматически.
Создай файл .github/workflows/build.yml вручную (текст есть в сообщении).
Крупные файлы: assets/music.pcm (11.5 МБ) - лимит веб-загрузки 25 МБ, влезает.
